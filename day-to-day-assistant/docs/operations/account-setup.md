# Account Setup

## First Run

Open the web application. If no active user exists, the application redirects to `/setup`.

Required fields:

- Email
- Display name
- Password
- Password confirmation
- Timezone
- Locale

After setup, `/setup` is disabled and the user signs in through `/login`.

## Recovery

Administrative recovery is not implemented in Phase 2. Recovery must be designed before any release that stores irreplaceable personal data.
