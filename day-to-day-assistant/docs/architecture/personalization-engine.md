# Personalization Engine

Personalization adapts interaction style without changing factual content or bypassing current user instructions.

Inputs include explicit preferences, learned preferences, relevant memories, routines, interaction context, and outcomes. Explicit settings and explicit preferences override learned behavior. Account settings such as timezone and locale override memory-derived values.

The engine returns explainable adjustments such as writing style, planning style, working hours, preferred units, and preferred day start. It does not optimize for engagement or conversation length; Phase D2D.9 outcome learning is limited to usefulness, completion, satisfaction, and reduced correction signals.
