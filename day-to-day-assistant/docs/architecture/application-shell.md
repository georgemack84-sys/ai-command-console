# Application Shell

The Phase 2 shell provides a stable navigational frame for future modules.

## Public Routes

- `/setup`
- `/login`
- `/session-expired`
- `/error`

## Protected Routes

- `/`
- `/health`
- `/settings`
- `/settings/profile`
- `/settings/preferences`
- `/settings/security`
- `/settings/sessions`

## Shell Regions

The shell includes a top bar, primary navigation, user menu, environment indicator, health indicator, main content region, error region, and disabled placeholders for future modules.
