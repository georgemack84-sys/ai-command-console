# Planning Behavior

Phase 7 turns assistant requests into structured, inspectable plans. The assistant classifies intent, extracts entities, retrieves minimal local context, selects read-only tools, composes a grounded answer, and explains its reasoning.

Supported initial intents include questions, search, summaries, recommendations, task requests, calendar requests, note requests, reminder requests, follow-up requests, navigation, help, and unknown requests.

The assistant still cannot modify tasks, notes, reminders, follow-ups, calendars, settings, files, or conversations through the planner.
