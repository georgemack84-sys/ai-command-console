# MVP Scope Record

## Included

- Local user authentication
- Application shell
- Tasks
- Reminders
- Local calendar
- Follow-ups
- Notes
- Today view
- Conversations
- One AI provider abstraction
- Deterministic mock AI provider
- Daily briefing
- Basic daily planning
- Action proposals
- Confirmations
- Activity history
- Memory controls
- Backup and restore

## Deferred

Email sending, external calendar synchronization, contacts synchronization, mobile applications, SMS, voice input, advanced semantic search, multi-user support, financial integrations, health integrations, multi-agent behavior, public deployment, and complex delegated automation are deferred.
