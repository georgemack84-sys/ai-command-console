# Nuru V1 Doctrine

1. Reasoning belongs to agents. Reliability belongs to services.
2. Agents propose. Governance authorizes.
3. Canonical knowledge must have provenance.
4. History is superseded, never silently erased.
5. An agent's confidence is evidence, not authority.
6. Every durable knowledge decision must be explainable and auditable.

Nuru V1 is a governed knowledge-curation architecture: specialized agents make
bounded judgments while deterministic infrastructure protects knowledge integrity.
