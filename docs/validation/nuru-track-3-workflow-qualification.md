# Nuru Track 3 workflow qualification

The Nuru-to-Headline Flow definition is immutable and versioned. Simulation checks configured active applications and capability declarations without external dispatch. Nuru evidence retrieval is read-only; the distinct Headline Flow draft step requires explicit approval. Admission records a `READY` run without dispatch. Runtime step authorization rechecks application lifecycle, credential, grant, dependency, and approval state before every step; recovery and observatory surfaces retain redacted execution evidence.

Track 3 does not authorize sandbox or staging egress. Those are Tracks 4 and 5.
